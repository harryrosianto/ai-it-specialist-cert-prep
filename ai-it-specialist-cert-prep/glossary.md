# Glosarium Istilah Penting

| Istilah | Definisi Singkat |
|---------|-------------------|
| **Adversarial attack** | Serangan yang memanipulasi input model (seringkali dengan perubahan kecil yang sulit dideteksi manusia) agar model menghasilkan prediksi yang salah |
| **Bias (algorithmic)** | Kecenderungan model menghasilkan hasil yang secara sistematis kurang akurat/adil terhadap kelompok tertentu, biasanya berasal dari data training yang tidak representatif atau mengandung bias historis |
| **Class imbalance** | Kondisi di mana satu kelas dalam data berlabel jauh lebih dominan jumlahnya dibanding kelas lain |
| **Classification** | Jenis masalah supervised learning dengan output berupa kategori/label diskrit |
| **Concept drift** | Perubahan hubungan antara input dan output (pola yang dipelajari model) seiring waktu |
| **Data augmentation** | Teknik memperbanyak variasi data (mis. rotasi/crop gambar) untuk meningkatkan generalisasi model |
| **Data drift** | Perubahan distribusi data input di produksi dibanding data yang digunakan saat training |
| **Decommission** | Menghentikan/menonaktifkan penggunaan model AI karena sudah tidak relevan atau tidak efektif |
| **Explainability** | Sejauh mana keputusan/prediksi model dapat dijelaskan dan dipahami oleh manusia |
| **Feature engineering** | Proses mengubah/mentransformasi data mentah menjadi fitur yang lebih berguna untuk model |
| **Feature vector** | Representasi numerik dari sekumpulan fitur yang mewakili satu sampel data |
| **Overfitting** | Model terlalu menyesuaikan diri pada data training sehingga performanya buruk pada data baru |
| **Underfitting** | Model terlalu sederhana sehingga gagal menangkap pola penting dalam data |
| **Precision** | Proporsi prediksi positif yang benar-benar positif: TP/(TP+FP) |
| **Recall (Sensitivity)** | Proporsi kasus positif sebenarnya yang berhasil terdeteksi: TP/(TP+FN) |
| **Specificity** | Proporsi kasus negatif sebenarnya yang berhasil terdeteksi: TN/(TN+FP) |
| **Regression** | Jenis masalah supervised learning dengan output berupa nilai numerik kontinu |
| **Reinforcement learning** | Paradigma pembelajaran di mana agent belajar melalui interaksi dengan lingkungan berdasarkan reward/penalty |
| **Robustness** | Ketahanan model dalam mempertahankan performa baik saat menghadapi data yang bervariasi atau tidak terduga |
| **Self-fulfilling prophecy (dalam AI)** | Model yang memperkuat bias historis karena dilatih dari data yang sudah mengandung bias tersebut, sehingga terus mereproduksi ketidakadilan yang sama |
| **Stakeholder approval** | Persetujuan dari pihak-pihak berkepentingan (manajemen, legal, pengguna) sebelum solusi AI dianggap final |
| **Subject-matter expert (SME)** | Pakar dengan pengetahuan mendalam tentang domain/bidang masalah tertentu (bukan pakar teknis AI) |
| **Supervised learning** | Pembelajaran menggunakan data berlabel (mencakup classification dan regression) |
| **Unsupervised learning** | Pembelajaran menggunakan data tidak berlabel untuk menemukan pola/struktur (mis. clustering) |
